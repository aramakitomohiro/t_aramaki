# VSCode Copilot Chat機能の使い分けガイド

VSCodeのCopilot Chat画面で表示される**Agent**、**Ask**、**Edit**の3つの機能について、それぞれの特徴と使い分け方法を説明します。

## 🤖 Agent（エージェント）

### 概要
Agentは最も高機能なAIアシスタントで、複雑なタスクを実行できる多目的なツールです。

### 主な特徴
- **コンテキスト理解**: プロジェクト全体の構造やコードベースを理解
- **複雑なタスク実行**: 複数ファイルにわたる変更や高度な実装が可能
- **対話型サポート**: 段階的な質問を通じて要件を明確化
- **包括的な回答**: 詳細な説明とコード例を提供

### 使用場面
- 新機能の実装方法を相談したい時
- アーキテクチャの設計について議論したい時
- 複数ファイルにまたがるリファクタリングが必要な時
- プロジェクト全体の改善案を求める時
- 技術選定やベストプラクティスについて相談したい時

### 使用例
```
Agent: 
「Reactアプリケーションで状態管理にReduxを導入したいのですが、
現在のコンポーネント構造を考慮した最適な実装方法を教えてください」
```

## ❓ Ask（質問）

### 概要
Askは素早い質問と回答に特化したシンプルな機能です。

### 主な特徴
- **迅速な回答**: 簡潔で要点を絞った回答
- **知識ベース**: 技術的な疑問に対する即座の解決
- **軽量**: 複雑な分析を必要としない質問に最適
- **学習支援**: 概念や構文の理解をサポート

### 使用場面
- 特定の関数やメソッドの使い方を知りたい時
- エラーメッセージの意味を理解したい時
- 簡単な構文について質問したい時
- 技術用語の定義を確認したい時
- クイックリファレンスが欲しい時

### 使用例
```
Ask: 
「JavaScriptのmap()とfilter()の違いは何ですか？」
「CSSのflexboxでアイテムを中央揃えにする方法は？」
```

## ✏️ Edit（編集）

### 概要
Editは既存のコードを直接編集・改善するための機能です。

### 主な特徴
- **インライン編集**: 選択したコードブロックを直接修正
- **具体的な変更提案**: 実際のコード変更を提示
- **リアルタイム編集**: 即座にコードの改善案を表示
- **精密な修正**: 特定の箇所に対する正確な変更

### 使用場面
- 既存のコードを改善したい時
- バグを修正したい時
- コードの最適化を行いたい時
- リファクタリングを実行したい時
- 特定の機能を追加したい時

### 使用例
```javascript
// 修正前のコード
function calculateTotal(items) {
    let total = 0;
    for(let i = 0; i < items.length; i++) {
        total += items[i].price;
    }
    return total;
}

// Editを使用して改善
// → より現代的な書き方への変換提案
```

## 🎯 効果的な使い分けのコツ

### Agentを選ぶべき時
- **複雑な問題解決**が必要
- **設計レベル**の相談をしたい
- **プロジェクト全体**への影響を考慮したい
- **段階的なアプローチ**で進めたい

### Askを選ぶべき時
- **素早い答え**が欲しい
- **単純な疑問**がある
- **学習目的**で使用する
- **リファレンス**として活用したい

### Editを選ぶべき時
- **既存コード**を改善したい
- **具体的な変更**を実行したい
- **実際のコード**が欲しい
- **即座の修正**が必要

## 💡 実践的な活用シナリオ

### シナリオ1: 新機能開発
1. **Agent**: 機能設計とアーキテクチャの相談
2. **Edit**: 実際のコード実装
3. **Ask**: 実装中の細かな疑問点を解決

### シナリオ2: 既存コードの改善
1. **Ask**: 現在のコードの問題点を理解
2. **Agent**: 改善戦略の策定
3. **Edit**: 具体的なコード修正

### シナリオ3: 学習・理解
1. **Ask**: 基本概念の理解
2. **Agent**: 詳細な説明と応用例
3. **Edit**: 実際にコードを書いて確認

## 📝 まとめ

| 機能 | 用途 | 回答の特徴 | 適用場面 |
|------|------|------------|----------|
| **Agent** | 包括的なサポート | 詳細・対話型 | 複雑なタスク・設計相談 |
| **Ask** | 素早い質問回答 | 簡潔・的確 | 学習・クイックリファレンス |
| **Edit** | コード編集支援 | 具体的・実践的 | 既存コード改善・実装 |

適切な機能を選択することで、より効率的で質の高い開発体験を得ることができます。
